# sanjidab74-cloud.github.io

Personal academic website of Sanjida Alom Borsa, served by GitHub Pages.
Plain HTML and CSS, no build step.

- `index.html` - home page
- `research.html` - the three studies, with diagrams and figures
- `cv.html` - web CV
- `style.css` - all styles
- `images/fig/` - research figures
- `data/Sanjida_Alom_Borsa_CV.pdf` - downloadable CV

To change the photo, replace `images/profile.jpg` with a square photo of the same name.
